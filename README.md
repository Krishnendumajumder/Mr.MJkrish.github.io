# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. This template is perfect for software engineers, web developers, and creative professionals looking to showcase their work and skills.

## Features

- 🎨 **Modern Design** - Clean, professional layout with smooth animations
- 📱 **Fully Responsive** - Works perfectly on all devices (desktop, tablet, mobile)
- ⚡ **Fast Performance** - Optimized for speed and user experience
- 🌙 **Dark/Light Mode Ready** - Easy to add theme switching
- 🔍 **SEO Friendly** - Semantic HTML5 structure
- ♿ **Accessible** - WCAG compliant with proper ARIA labels
- 📧 **Contact Form** - Functional contact form with validation
- 🎯 **Smooth Scrolling** - Seamless navigation between sections
- ✨ **Interactive Elements** - Hover effects, animations, and transitions

## Sections

1. **Hero Section** - Eye-catching introduction with call-to-action
2. **About Section** - Personal information and highlights
3. **Skills Section** - Technical skills and technologies
4. **Projects Section** - Portfolio showcase with project details
5. **Experience Section** - Work history timeline
6. **Contact Section** - Contact form and social links

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Flexbox and Grid
- **JavaScript (ES6+)** - Interactive features and animations
- **Font Awesome** - Icon library
- **Google Fonts** - Typography (Inter font)

## Getting Started

### Prerequisites

- A modern web browser
- A code editor (optional, for customization)

### Installation

1. Clone or download this repository
2. Navigate to the project directory
3. Open `index.html` in your web browser

### Customization

#### Personal Information

Update the following files with your information:

**`index.html`**:
- Change "Your Name" throughout the document
- Update your job title
- Modify the about section description
- Add your actual projects
- Update work experience
- Add your contact information

**Contact Links**:
```html
<!-- Update these links with your actual profiles -->
<a href="https://github.com/yourusername" class="social-link">
<a href="https://linkedin.com/in/yourusername" class="social-link">
<a href="mailto:your.email@example.com" class="social-link">
```

#### Styling

**`css/style.css`**:
- Modify colors in the CSS variables section
- Adjust fonts and spacing
- Customize animations and transitions
- Change the gradient backgrounds

#### Projects

To add new projects:

1. Copy an existing project card in `index.html`
2. Update the project details:
   - Project title and description
   - Technologies used
   - Live demo and GitHub links
   - Add project screenshot

#### Skills

Update the skills section by:
1. Modifying skill categories
2. Adding/removing skill items
3. Updating icons and labels

## Deployment

### GitHub Pages

1. Push your code to a GitHub repository
2. Go to repository settings
3. Enable GitHub Pages
4. Select the main branch as source
5. Your site will be available at `https://yourusername.github.io/repository-name`

### Netlify

1. Push your code to a Git repository
2. Sign up for Netlify
3. Connect your repository
4. Deploy your site

### Vercel

1. Push your code to a Git repository
2. Sign up for Vercel
3. Import your project
4. Deploy your site
